Singly Linked List in C

Nodes created dynamically using malloc(). Each node stores data and a next pointer, terminated with NULL.

Insert Head: O(1) Insert Tail: O(n) Delete Head: O(1) Delete Tail: O(n)

Doubly Linked List in C

Bidirectional chain with prev and next pointers. Enables $O(1)$ deletions at the tail when maintaining a tail pointer.

Insert Head: O(1) Insert Tail: O(1) Delete Head: O(1) Delete Tail: O(1)

Circular Linked List in C

Ring topology where tail->next == head. No NULL pointers. Traversal cycles endlessly through the chain.

Insert Head: O(1) Insert Tail: O(1) Delete Head: O(1) Delete Tail: O(n)
